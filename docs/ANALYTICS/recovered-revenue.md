# Filters

<table class="rp-params">
  <tr class="rp-thead-row"><td>Filter</td><td>Description</td></tr>
  <tr><td>Include Invoices Based On</td><td>Chooses which date places an invoice in the reporting period, such as closed date. Defaults to Closed Date.</td></tr>
  <tr><td>Date Range</td><td>The reporting period. Defaults to the past 18 months.</td></tr>
  <tr><td>Timeframe</td><td>The interval used to group trends, such as month. Defaults to Month.</td></tr>
  <tr><td>Invoice Type</td><td>Filters by invoice type. Defaults to All.</td></tr>
  <tr><td>Show Prior Recovery</td><td>Chooses whether to include the revenue impact of previously recovered subscriptions in the totals. Defaults to No.</td></tr>
</table>

# Key metrics

<table class="rp-params">
  <tr class="rp-thead-row"><td>Metric</td><td>Description</td></tr>
  <tr><td>Recovered Revenue Amount</td><td>The total value of at-risk invoices — invoice amounts that closed as paid after exiting a retry window — during the selected period.</td></tr>
  <tr><td>Recovered Invoice Count</td><td>The number of at-risk invoices that closed as paid after exiting a retry window during the selected period.</td></tr>
  <tr><td>Month-to-Date Recovered Revenue</td><td>The revenue recovered so far in the current month, compared to the same point in the previous period.</td></tr>
  <tr><td>Month-to-Date Recovered Count</td><td>The number of invoices recovered so far in the current month, compared to the same point in the previous period.</td></tr>
</table>
