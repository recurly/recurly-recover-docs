# Common controls

These controls are available across every Recover Analytics dashboard:

<ul class="rp-list">
  <li><strong>Hover</strong> over any chart to see detailed values for a specific point or segment.</li>
  <li><strong>Toggle</strong> items in a chart legend to show or hide them.</li>
  <li><strong>Export</strong> any chart or table to download its data.</li>
</ul>
